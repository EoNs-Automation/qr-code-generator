# QR Code Generator

A simple tool that generates QR codes from text or URLs.

## Features

- Generate QR codes from any text or website link
- Download the QR code as an image
- Clean dark-themed web interface
- Available as both a Python script and a web tool

## Live Demo

[Try the web version here](https://qr-code-generator-6c457e.netlify.app/)

Also in the EoNs Tools Hub:

## How to Use (Python)

1. Run the script
2. Enter the text or URL you want to encode
3. The QR code is saved as an image in the `qrcodes` folder
4. Type `quit` to exit

## Example
Enter text or URL to encode: https://eonsautomation.dev
QR Code saved as 'eonsautomation-dev-qrcode.png'
